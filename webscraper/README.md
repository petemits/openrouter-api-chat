# Advanced Web Scraper

A comprehensive Node.js web scraping application with multiple scraping methods and ethical practices.

## Features

- **Multiple Scraping Methods**: Cheerio (static), Puppeteer (dynamic), Enhanced (protected sites)
- **Ethical Scraping**: robots.txt checking, rate limiting, delays
- **Anti-Bot Protection**: Stealth techniques for protected websites
- **Web Interface**: User-friendly frontend for easy scraping
- **REST API**: Programmatic access to all scraping functions
- **Proxy Support**: Configurable proxy rotation
